## 基於哪一版
3b91e22327d78ccbe1b93fe61be51d0200701d4c

## 改了什麼
先固化 22:00 的來源時序：新榜單 E+1.456 秒、首讀 E+3.271 秒、分類只剩到 E+4.201 秒、原分析 E+7.797 秒才到。用原 EntryFeed、CaptureBridge 與 SQLite observer 驗證，先前快取不可掩蓋仍可在共享限額內提早核實分類的情況。

## 解決了什麼
避免廣播每個候選都繼承同一個即將過期的分類時鐘；仍以實際發布來源和新分類的共同有效範圍為準。
