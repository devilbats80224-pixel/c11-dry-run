# C11：已驗證的本機連續 1m 不受上市新舊限制

## 基於哪一版
daf7b0c8985d1f5efa40f73426c51c7d9d0ff657

## 改了什麼
新增無已存狀態、但本機已有已驗證完整 1m 的舊合約案例，以及缺一根的反例。

## 解決了什麼
上市時間不是拒絕已驗證歷史的理由。符合相同來源、連續性及時間核對的本機分鐘資料可以送去重建，不先向外重抓。

## 尚未解決或未驗證
沒有可信完整資料、特別長或狀態曾中斷的資料仍需補足或找到已驗證斷點。不得拿一小段行情當作完整策略狀態。

## 保留項目與驗證
不改候選入口、策略有效期、策略算法、帳本、安全或流量控管。必要範圍由查證後的歷史缺口決定。
