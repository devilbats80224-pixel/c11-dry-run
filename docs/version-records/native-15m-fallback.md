補修回榜案例：原策略在本輪第一次分析時核對到尚有缺段，接著另一條原生路線補齊，使後續排程以剩餘 0 根誤略過交接。只保留首度已驗的同輪、同候選、同代及原有效期，不借舊榜或延長期限；本路只採原生 1m 證據，不開啟較寬週期備援。修前規劃回歸確實紅燈，修後在隔離映像通過，端到端仍由此 PR 最新提交的 Worker 檢查。

把同一份 JCT 近期狀態接到真正的 Reviewed Catalog 入口：以已核對的截止時間、原始清單指紋、RPD、雙週期 ATR 與連續已收盤 15m 一併封存並釘住摘要。冷啟動只讀這份狀態，不重開舊封存；若已宣告的狀態檔不存在、過期、摘要不符或資料身分不符，拒絕該檔且不悄悄回到上市日。尚無核對狀態的新候選不因此獲得狀態，不改其現行安全政策。原始封存讀取及遠端固定來源的獨立檢查保留。正式驗收仍需新提交／最新封裝通過。
