# C11：從已驗證的舊斷點，按缺口與共用額度平行取數

## 基於哪一版
daf7b0c8985d1f5efa40f73426c51c7d9d0ff657

## 改了什麼
模擬同幣可用額度同時允許多段，並故意讓後段先抵達。需能抓互不重疊的時間段，不能讓策略狀態跨過尚未驗證的第一段。

## 解決了什麼
回歸證明舊程式即使還有配額也每幣只排一段。應由實際缺口與原共用額度決定，而不是寫死每幣幾頁。

## 尚未解決或未驗證
本項只處理已有已驗斷點；沒有任何可信起點的幣走各自的自動重建路徑，不能把結果互換。上線仍需真實收盤驗證。

## 保留項目與驗證
保留不可重複、順序因果、原帳本/策略時限、共同額度及實際可用的候選範圍。
