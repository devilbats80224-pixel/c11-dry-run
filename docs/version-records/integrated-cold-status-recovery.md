## 改了什麼
整合三項回歸：過了原「近期上市」界線仍能由已驗完整本機原始行情重建；按時間缺口與實際配額平行請求；續接 RPD 與兩種 ATR。自動公開封存不以累計檔數或位元組停止，在每個短批次驗證完整檔、保留進度後續跑；不放寬釘選審核來源、單檔安全或資料完整性。測舊幣完整、少一根、網路不必要而不觸發、後段早到、相交去重以及原斷點順序。另同輪送兩個不同缺口的候選，在同一共享預算下交錯派發，短缺口不等長缺口完成。保留行情超過 260 根 15m 時改按區塊投影、跨塊續算同一個原狀態，不把讀取區塊大小當重建上限；缺少接縫的 1m 仍拒絕。移除候選輪替時備援佇列的 64 筆拒收條件。不同現行候選的封存準備互不阻塞，仍依真實退避共同收斂；已完成結果只由原單一擁有者核對後寫入。行情補資料不再套用交易判斷路徑專用的固定 1,200 預留，按當期外部上限、已用權重、排隊及實際已預留保護計算。已有連續完整 1m 時只在本機重建缺少的合成 K，不重抓整段，保留原已核對的列並接著更新 RPD 和兩種 ATR。

## 解決了什麼
移除已驗證資料的上市新舊門檻、同幣一次只能一段的硬限制，以及原歷史續接只更新 RPD 沒續 ATR。保留原時間、原續接證明及同輪有效期。

仍不把缺了可信資料的情況判為完整重建。特別長且未有可信斷點的情形需繼續找可查證的行情；本版未複製未驗歷史狀態。整套綠燈後仍須 Mac Docker 真實收盤驗收。
